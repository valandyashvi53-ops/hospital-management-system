## 🚀 How to Run the Project

Since this is a **PHP project**, it needs a PHP-enabled local server.

### Using PHP Built-in Server

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
php -S localhost:8000
```

5. Open your browser.
6. Visit:

```text
http://localhost:8000
```

---

## 🖥️ Using XAMPP

You can also run the project using XAMPP.

Place the project inside:

```text
C:\xampp\htdocs\
```

For example:

```text
C:\xampp\htdocs\hospital-management-system\
```

Start **Apache** from XAMPP and open:

```text
http://localhost/hospital-management-system/
```

If the project uses MySQL, also start **MySQL** from XAMPP.

---

## 🗄️ Database

If the project contains a MySQL database:

1. Start Apache and MySQL.
2. Open phpMyAdmin.
3. Create the required database.
4. Import the project's `.sql` file if provided.
5. Update the database connection settings in the PHP configuration file.

Example:

```php
$host = "localhost";
$username = "root";
$password = "";
$database = "hospital_db";
```

Make sure the database name matches your project configuration.
